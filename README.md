# WovenRealm / 织境空间

织境空间是一个面向 **Degrees of Lewdity** 的 AI 剧情与 AI 场景图 Mod。它会在原版剧情旁加入 AI 剧情生成、后续选项、记忆、AI 道具和场景图生成能力，让玩家可以在不破坏原版流程的前提下扩展剧情分支。

当前版本：`v0.1.474`

## 主要功能

- **AI 剧情生成**：在适合扩展的原版选项后追加“剧情生成”按钮。
- **AI 后续选项**：AI 剧情页会生成后续选项，支持继续推进、刷新剧情、返回原版章节和强制调整剧情地点。
- **选项微调**：AI 选项前的“改”按钮可微调剧情文字和耗时，耗时以原版格式显示。
- **记忆系统**：保存短期剧情、长期重点记忆和玩家自定义剧情倾向。
- **AI 道具系统**：剧情中出现可拾取物品时，玩家可选择收入 AI 库存，并在后续剧情生成中使用。
- **AI 场景图生成**：根据当前剧情、地点、角色、玩家外观和绘图设定生成场景图提示词，并可调用本地或兼容接口生成图片。
- **错误报告**：可导出诊断文本，便于反馈问题。报告会包含当前剧情内容和诊断信息，但不会包含 API 密钥或完整存档。

主包只包含剧情生成与场景图功能，不包含亲密扩展内容。

## 安装方法

1. 下载 `织境空间-v0.1.474.zip`。
2. 将 zip 放入游戏目录的 `mods` 文件夹。
3. 启动 `Degrees of Lewdity.html`。
4. 在标题界面或游戏内打开 ModLoader 并加载本 Mod。
5. 进入游戏设置中的 AI 设置页，填写 API 信息并按需调整选项。

压缩包内的 `boot.json` 必须位于 zip 根目录。如果重新打包，请不要把整个外层文件夹套进 zip。

## 初次设置

建议至少检查：

- API Key
- 后台地址 / Endpoint
- 模型名称
- 高质量后台
- 语言
- 文风设定
- 玩家个人设定
- 绘图设置

设置完成后，先使用设置页里的连接测试确认接口可用。

## 使用说明

正常游玩原版游戏即可。当页面适合扩展剧情时，原版选项后会出现 `[剧情生成]`。

常见操作：

- 点击原版选项：正常进入原版剧情。
- 点击 `[剧情生成]`：基于该选项生成 AI 剧情。
- 点击 `刷新剧情`：重新生成当前 AI 剧情。
- 点击 `使用道具`：打开 AI 库存，选择要带入下一段剧情的物品。
- 点击 `返回原版章节`：离开 AI 剧情，回到对应原版章节。
- 点击 `强制调整剧情地点`：当 AI 推断地点错误时，手动选择更合适的原版地点。
- 点击 `☆ 收藏剧情进长期记忆`：把当前剧情摘要写入长期记忆。

## 注意事项

- 本 Mod 需要可用的 AI 接口；接口不可用时，剧情和选项生成会失败。
- API Key 属于私人信息，请不要上传、截图或打包分享。
- AI 生成内容可能出现地点、角色、数值或道具判断错误，遇到错误时可使用刷新、返回原版章节或强制调整剧情地点。
- 建议经常导出游戏存档。
- 本项目不是 Degrees of Lewdity 官方内容，也不隶属于原作者团队。
