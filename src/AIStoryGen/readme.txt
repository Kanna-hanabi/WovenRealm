WovenRealm / 织境空间 v0.1.318
================================

这是 Degrees of Lewdity 的 AI 剧情与 AI 场景图公开版 Mod。

主要功能
--------
1. AI 剧情生成：在适合扩展剧情的原版选项后追加“剧情生成”。
2. AI 后续选项：AI 剧情页生成后续选项，可继续推进、刷新剧情、返回原版章节或手动调整剧情地点。
3. 时间编辑：AI 选项时间以原版格式显示，点击时间可展开小时/分钟调节条，也可直接输入。
4. AI 记忆：记录短期剧情、长期重点记忆和玩家自定义剧情特点。
5. AI 道具：剧情中出现可拾取物品时，玩家可选择收入库存，并在后续剧情中使用。
6. AI 场景图：根据当前剧情、地点、角色、玩家外观和绘图设定生成场景图提示词并调用绘图接口。
7. 错误报告：可导出诊断文本，便于反馈问题。报告会包含当前剧情内容和诊断信息，但不会包含 API 密钥或完整存档。

安装方法
--------
1. 将 `织境空间-v0.1.318-公开版.zip` 放入游戏目录的 `mods` 文件夹。
2. 启动 `Degrees of Lewdity.html`。
3. 在标题界面或游戏内打开 ModLoader。
4. 加载本 Mod。
5. 进入游戏设置中的 AI 设置页，填写 API 信息并按需调整选项。

注意事项
--------
- 本公开版不包含亲密扩展内容。
- AI 生成内容来自玩家配置的模型服务，效果、速度和稳定性取决于所使用的接口与模型。
- 请经常导出游戏存档。
- 反馈 bug 时建议附带 Mod 导出的错误报告。
